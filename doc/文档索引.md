# 文档索引

## 权威文档

- `课题介绍.docx`：产品背景和评分要求。
- `API.md`：修正后的用户端 REST API 人类可读文档。
- `openapi/rest-api.openapi.json`：与 `API.md` 严格对应、可导入 Apifox 的用户端 REST OpenAPI 3.0 文档。
- `openapi/default.openapi.json`：当前 REST API 文档。
- `openapi/live-room-websocket.openapi.json`：当前 WebSocket API 文档。
- `拍卖客户端实时交互方案.md`：实时客户端交互、seq 去重、快照恢复和 UI 状态建议。
- `接口对齐文档.md`：前后端接口采纳、修正和追加记录。
- `用户端实现说明.md`：当前用户端实现范围和技术说明。
- `Mock控制桥使用说明.md`：本地开发测试工具说明。
